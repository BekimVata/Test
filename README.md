# Banians office

The Eagle's Office (Zyra e Shqiponjës) for the Banians Etsy shop.

Agents research, design (Ideogram), get checked by the master eagle (Claude), go to you for approval in Telegram, then become Printify products published to Etsy. The pixel office shows it all live.

* Install on a fresh Ubuntu 24.04 server: see the setup guide you were given, or run
  `curl -fsSL https://raw.githubusercontent.com/BekimVata/Test/banians-office/install.sh | OFFICE_PASSWORD='choose-a-password' bash`
* Update later: run the same command again (settings and data are kept).
* Practice mode on any computer with Node 22: `npm run practice`, then open http://127.0.0.1:3000 (password `practice123`).

No secrets live in this repository. Keys are pasted into the office Settings page and stored on the server only.
